# اختبار الوحدة 1 — أنظمة تكنولوجيا المعلومات

افتح `index.html` في المتصفح. الاختبار من 60 سؤالاً موقفياً للصف الأول الثانوي. العربية هي اللغة الأصلية، وزر اللغة يبدّل الأسئلة والخيارات والتغذية الراجعة إلى الإنجليزية. ترتيب الأسئلة والخيارات يتغير في كل محاولة.

## سجل النتائج

العلامات التفصيلية تُكتب في [جدول النتائج](https://docs.google.com/spreadsheets/d/1wn0xkxn6om9hIAsEoQYac6Gr9lSoN477wSL5weFHt5U/edit).

رابط الإرسال موجود داخل `index.html`. كل محاولة تكتب صفاً واحداً في ورقة «النتائج» (الوقت، الاسم، العلامة، من، النسبة، التصنيف، نتاج أ، نتاج ب، نتاج ج)، وصفّاً لكل سؤال في ورقة «التفاصيل» (الوقت، الاسم، رقم السؤال، الرمز، النتاج، صحيح أو خطأ، اختيار الطالب). رقم السؤال هو رقم السؤال في البنك، لا ترتيب ظهوره في المحاولة.
